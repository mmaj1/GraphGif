# Wstęp
Jest to interpreter własnego języka grafowego na animacje algorytmu w graphviz. W interpleterze możemy definiować grafy, ich węzły oraz krawędzie. Można również deklarować zmienne, kolory i kształt węzłów. Grafy oraz zdefinioawne wcześniej zmienne będzie można zastosować w różnych funkcjach (np. BFS() Bredth-First Search).

#Cele
Celem projektu jest stworzenie interpretera, za pomocą którego będzie można stworzyć grafy, oraz komendy które będą przeprowadzać algorytmy na stworzonych grafach. Następnie możliwe będzie wyświetlenie grafu, animacji algorytmu w graphviz
